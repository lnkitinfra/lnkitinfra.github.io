# LNK IT Infra | Enterprise IT Infrastructure, Products & Services (Pune & PCMC)

Official web portal and infrastructure catalog for **LNK IT Infra Pvt. Ltd.** — providing end-to-end office IT setups, structured network cabling, genuine enterprise hardware products, turnkey IT solutions, and comprehensive Annual Maintenance Contracts (AMC) across Pune and PCMC.

## Core Offerings

### 1. Products
- **SOPHOS**: Next-Gen Firewalls (XGS 116 / 126 / 2100), AP6 Wi-Fi 6 Access Points, Sophos Central Endpoint Protection.
- **FORTINET**: FortiGate Security Gateways (FG-60F / 80F / 100F), Secure SD-WAN, and FortiSwitch managed fabrics.
- **SONICWALL**: Multi-Gigabit Next-Gen Firewalls (TZ470, TZ570 series) with real-time deep packet inspection.
- **SYNTEL**: Office Intercom and Telephony Systems (NEO DX 206/308, 312/416 & NEOX IP-PBX Hybrid Systems).

### 2. Solutions
1. **Server & Storage Solutions**: Dell PowerEdge & HPE ProLiant rack servers, hardware RAID, and centralized SAN/NAS.
2. **IT Security Solutions**: Perimeter Next-Gen UTM firewalls, zero-trust architectures, and secure remote VPNs.
3. **Networking Solutions**: HPE Aruba Instant On & Cisco Catalyst managed PoE+ switches, commercial Wi-Fi 6 mesh, and VLANs.
4. **Structured Cabling**: CommScope Systimax & Schneider Cat6/Cat6A LSZH cabling, rack dressing, and Fluke DSX pass testing.
5. **Server & Backup Solutions**: Automated 3-2-1 backup strategies, Veeam, Synology Active Backup, and APC Smart-UPS power.
6. **CCTV Solutions**: Hikvision 4K Ultra-HD IP security cameras, 30-day NVR recording, and mobile app monitoring.
7. **Biometric Attendance Solutions**: AI facial recognition & fingerprint time-attendance with automated payroll sync.
8. **Door Access Solutions**: Electromagnetic (EM) door locks, RFID proximity cards, and emergency fire alarm fail-safes.

### 3. Services
1. **IT Infrastructure Solutions**: Turnkey Day-1 office IT layout planning, server room engineering, and ISP handover.
2. **IT Health Checkup & Auditing**: Fluke DSX cable certification, rack thermal scanning, and firewall security audits.
3. **Software Licensing**: Official Microsoft 365, Windows Server CALs, Sophos Endpoint, and Tally Prime multi-user licenses.
4. **Project Management Tools**: IT relocation management, telecom ISP coordination, network topology diagrams, and timelines.
5. **Computer / Laptop Sales & Support**: Corporate laptop rentals (Dell, Lenovo, Apple), commercial desktops, and standby replacements.
6. **Annual Maintenance Contract (AMC)**: Comprehensive/Non-comprehensive plans with guaranteed 1-hour Pune emergency SLA.
7. **Remote Support & Onsite Support**: Instant AnyDesk remote helpdesk and same-day physical engineer dispatch in Pune & PCMC.

## Tech Stack

- **Framework**: React 19 + TypeScript
- **Bundler**: Vite
- **Icons**: Lucide React
- **Styling**: Modern Responsive CSS3 (Custom Variables, Light Foundation with Sky Tints)
- **Deployment**: GitHub Pages (`https://lnkitinfra.github.io`)

## Local Development

```bash
# Install dependencies
npm install

# Start local development server
npm run dev

# Typecheck and build for production
npm run build

# Preview production build locally
npm run preview
```
